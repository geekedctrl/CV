VERO Online Ticketing Platform with Blockchain Smart Contract Ongoing

Year: 2025
Type: Commercial Project
NuxtJs PostgreSQL JWT Bcrypt FastAPI

Built a FastAPI backend with JWT auth and simple RBAC for an online ticketing platform with blockchain smart contract integration. Implemented comprehensive event management, secure ticket purchasing with QR-based entry, and user-to-user resale marketplace.

Key Features:

  • Built a FastAPI backend with JWT auth and simple RBAC
  • Implemented event creation, ticket purchase, and QR-based entry with single-use, expiring tokens and server-side validation
  • Added a user-to-user resale flow: sellers list tickets at a fixed +20% markup, buyers purchase, and ownership transfers with full audit trail
  • Enforced state machine for tickets to prevent reuse and block entry for listed/sold tickets
  • Integrated payments and wrote webhook handling to finalize transfers only after confirmed payment
